# Governance

## Built

The repository contains clear Bronze, Silver, and Gold boundaries, ingestion metadata, pipeline control, run logs, failure records, schema-change logging, and configuration-driven transformation rules.

## Planned or Service-Managed

Microsoft Purview catalog registration, automated lineage, classification, sensitivity labels, access groups, certified semantic models, Data Agent configuration, and Microsoft 365 Copilot integration are managed in Fabric and Microsoft 365 services. They are not stored as repository configuration files.
